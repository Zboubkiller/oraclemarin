# Oracle Marin

**Un labo d'outils web insolites, gratuits et en français** — mer et surf, apprentissage, productivité, cartes, jeux et satire. Chaque outil est une page indépendante, accessible sans installation.

Site : **https://oraclemarin.fr** · À propos : https://oraclemarin.fr/apropos/ · Par [Quentin Closset](https://github.com/Zboubkiller), Perros-Guirec (France)

![Oracle Marin : les outils](https://oraclemarin.fr/og-oraclemarin.png)

> Ce dépôt est une **vitrine** : il présente les outils. Seul le code de [ça brûle](https://github.com/Zboubkiller/ca-brule) est publié.

## Actualité et données

| | |
|---|---|
| **[ça brûle](https://oraclemarin.fr/cabrule/)** | Carte en direct des manifestations, grèves et blocages en France, ville par ville, construite à partir de la presse en ligne, mise à jour toutes les 10 minutes. Code : [ca-brule](https://github.com/Zboubkiller/ca-brule). |

## Mer et sport

| | |
|---|---|
| **[Cap ou Pas Cap](https://oraclemarin.fr/capoupascap/)** | Indique si l'on peut sortir en mer aujourd'hui : marée et coefficient, vent, houle et météo marine, avec une page dédiée par port (plus de 390 ports). |
| **[Oracle Surf](https://oraclemarin.fr/surf/)** | Même principe pour le surf : spot et style de glisse, vent, houle, température de l'eau, score de fun et prévisions sur 24 heures. |

## IA et apprentissage

| | |
|---|---|
| **[Revisia](https://oraclemarin.fr/revisia-app/)** | Transforme un cours, un PDF ou un sujet en quiz interactif. |
| **[Tip Of My Tongue](https://oraclemarin.fr/tipofmytongue/)** | Retrouve le titre d'un jeu vidéo, d'un film, d'une série ou d'un livre à partir de souvenirs flous. |
| **[Savoir Scroll](https://oraclemarin.fr/savoir-scroll/)** | Un fil qui défile à l'infini, mais pour apprendre : articles Wikipédia, images, vidéos de vulgarisation, lectures. |
| **[2minWebsite](https://oraclemarin.fr/2minWebsite/)** | Génère un site web complet pour un commerce ou un artisan à partir de quelques informations. |
| **[Agent Guard](https://oraclemarin.fr/agent-guard/)** | Contrôle en temps réel qui détecte manipulation, fuites de données et contenus dangereux avant qu'ils n'atteignent un agent IA. |

## Jeux, fun et satire

| | |
|---|---|
| **[Détective](https://oraclemarin.fr/detective/)** | Jeu d'enquête façon film noir des années 1940, avec interrogatoires de suspects pilotés par IA. |
| **[Search History Leak](https://oraclemarin.fr/SearchHistoryLeak/)** | Projet satirique : l'historique de recherche fictif de n'importe quel personnage. |
| **[LiveZap](https://oraclemarin.fr/live-zap/)** | Zapper entre de vrais concerts live et des sessions complètes (chaînes YouTube et Twitch vérifiées). |
| **[Beer-Meter](https://beer-meter.oraclemarin.fr/)** | Calcule combien de bières ou de barbecues un ami vous doit après un coup de main. |

## Vie privée et productivité
